#Aplicación de Mensajería

Se realizó una modificación de un proyecto de Python con interfaz gráfica
utilizando Tkinter.

#Modificaciones realizadas

- Se corrigió el título de la aplicación.
- Se agregó una imagen personalizada.
- Se configuró el envío de correos mediante Gmail.
- Se agregó un menú desplegable para seleccionar destinatarios.
- Se agregó un campo para ingresar otro correo manualmente.
- Se generó un archivo ejecutable `.exe`.

## Funcionamiento

La aplicación permite ingresar un asunto, un mensaje, y seleccionar un
destinatario.
